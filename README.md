# 🎓 PreliNation — Landing Page

A high-conversion landing page for **PreliNation**, Bangladesh's premier government job exam preparation platform targeting BCS and NTRCA candidates.

🔗 **Platform:** [test-bd.info/login](https://test-bd.info/login)

---

## 📌 Overview

Built on a modern SaaS-style template while preserving PreliNation's existing brand identity — CSS variables, color palette, fonts, and style system — this landing page is designed to convert visitors into active students.

---

## 📐 Page Structure

| # | Section | Description |
|---|---------|-------------|
| 1 | **Header** | Logo, navigation, login button, CTA |
| 2 | **Hero** | Headline, subheadline, CTAs, trust indicators |
| 3 | **Stats Counter** | Animated numbers — questions, students, exams |
| 4 | **Why PreliNation** | Platform benefits and differentiators |
| 5 | **Feature Grid** | Unique question sets, smart exam system, etc. |
| 6 | **Exam / Analysis / Premium** | 3-column feature breakdown |
| 7 | **Value Proposition** | Unique system methodology explained |
| 8 | **Visual Experience** | Mobile UI, dashboard, analytics gallery |
| 9 | **Testimonials** | Student success stories (slider) |
| 10 | **Pricing** | Free, Premium, and Pro plans |
| 11 | **Contact & Support** | WhatsApp, Messenger, Phone, Facebook |
| 12 | **Footer** | Links, copyright, social icons |

## 🚀 Getting Started
```bash
git clone https://github.com/ShuvroShimuL/Prelination.git
cd Prelination

# Option 1: Open directly
open index.html

# Option 2: Local server
npx serve .
# or
python -m http.server
```

---

## 🎨 Customization

- **Colors & Fonts** → edit CSS variables in `assets/css/template.css`
- **Images** → replace placeholders in `assets/images/` (maintain aspect ratios)
- **Links** → update `href` attributes in `index.html` for social, contact, and pricing URLs
