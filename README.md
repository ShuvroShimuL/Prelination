# PreliNation Landing Page

A high-conversion landing page for the PreliNation government job preparation platform, built using modern SaaS design patterns.

## Features

- **12-Section Structure**: From Hero to Footer, including Pricing, Testimonials, Analytics, and Contact sections.
- **Glassmorphism Design**: Modern UI with depth and floating elements.
- **Interactive Dashboard Mockup**: A high-converting hero section with interactive HTML/CSS mockups.
- **AOS Animations**: Staggered scroll animations applied to components for a modern feel.
- **Responsive**: Fully optimized for mobile, tablet, and desktop.
- **Interactive JS Components**: Notice ticker, stats counter, testimonial slider, gallery slider.

## Structure

- `index.html`: The main landing page document.
- `assets/css/style.css`: Custom overrides, glassmorphism, and structural improvements.
- `assets/css/bootstrap.css`: Base Bootstrap grid and framework.
- `assets/css/template.css`: Original theme variables and colors.
- `assets/js/main.js`: Interactive elements, sliders, and stats counter.
- `assets/fonts/`: Theme typography and icons.

## How to View

Simply open `index.html` in your favorite web browser.
